# Snowflake stored procedures

Source for the ~78 team-built procedures (SQL and Python). None are in Git yet — pull each one's definition here as it gets touched, so changes are reviewable.

The full inventory, with what each one does and known problems, is the "Stored procedures" tab of `docs/current-state/current_state_processes.xlsx`. Several contain hard-coded credentials — never commit a procedure body without removing those first.
