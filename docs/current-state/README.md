# Current state

A snapshot of the data stack as of **November 5, 2026**. Nothing here is a plan — it describes what runs today.

- `current_state_processes.xlsx` — inventory of all 115 automated processes. Tabs: Start here, Processes, Top issues, Salesforce detail, Stored procedures, Still to check, Warehouse map.
- `rays_data_stack_2.html` — visual summary of the same findings (open in a browser).
- `summary.md` — plain-language summary: the stack, the top issues, and what hasn't been checked yet.

Known glitches in the source files (confirmed Nov 2026): the HTML's "878 procedures" disagrees with the xlsx footnote (~8,607); "14 test/debug copies" undercounts the ~37 procedures marked "Test or old copy"; two "Still to check" rows say DONE in the text but "Not started" in the Status column; `OpportunityBefore` is listed twice in Salesforce detail.
